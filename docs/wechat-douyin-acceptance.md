# 微信模式（抖音气泡）启动与验收

## 启动

在 PowerShell 中运行：

```powershell
cd D:\deepseekharness\moyu-replica
npm run dev
```

如果终端提示 `boss (Ctrl+D)：快捷键已被占用`，先关闭旧版 MoYuMaster、之前启动的复刻程序，再重新运行。

## 验收路径

1. 首页点击“抖音微信模式”，出现正式微信仿真界面。
2. 点击输入区上方的文件夹按钮，在当前会话插入抖音网页气泡；同一会话重复点击不会创建第二个播放器。
3. 在气泡里点击、滚轮浏览和登录抖音；切换会话时播放器保留并暂停，切回后恢复原气泡。
4. 右上角“…”可调整横竖屏、大小、网页地址、发送方和交互遮罩，也可编辑联系人及导入/导出本地 JSON。
5. 输入消息按 Enter 发送；Ctrl+Enter 或 Shift+Enter 换行。聊天内容只存本机，不会发送给真实微信联系人。
6. 使用系统设置的老板键时，微信窗口保持可见，仅用动态图遮挡播放器；再次按下恢复。
7. 关闭再打开，检查消息、草稿、设置和播放器地址是否恢复。
