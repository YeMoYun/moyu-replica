# 钉钉模式（抖音气泡）启动与验收

## 启动

```powershell
cd D:\deepseekharness\moyu-replica
npm run dev
```

若提示 Ctrl+D 被占用，请先关闭旧版 MoYuMaster 或之前启动的复刻程序，再重新启动。

## 验收

1. 首页点击“钉钉模式”，确认蓝色顶部栏、左侧功能导航、五个本地会话和圆角输入区。
   尝试拖动顶部蓝色空白区域，确认无边框窗口可移动；搜索框仍可正常输入。
2. 输入本地消息：Enter 发送，Shift+Enter 换行；消息不会发送到真实钉钉。
3. 点击文件夹按钮插入抖音气泡，在小窗口中直接点击、滚轮和登录；重复点击不会创建第二个播放器。
4. 右上角“…”调整网址、横竖屏、大小、发送方和交互遮罩；检查布局变化不刷新已有气泡。
5. 切换会话后再切回，确认播放器仍是原气泡；草稿仍在。
6. 使用老板键，确认钉钉窗口不消失、只遮挡播放器，再次按下恢复。
7. 同时打开微信与钉钉，确认联系人、消息、设置和抖音登录状态互不共享。
8. 关闭重开并重启程序，检查消息、草稿、配置和播放器地址恢复。

自动化验证使用隔离的本地网页，不读取用户账号。真实抖音登录、推荐流和在线播放需在本机网络环境中人工验收。
