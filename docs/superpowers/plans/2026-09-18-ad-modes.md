# 抖音与微信读书独立广告模式 Implementation Plan

> 执行方式：本会话逐项执行，不创建 Git/worktree，不委派子代理。用户已批准独立广告视图与按模式分派老板键的方案。

**Goal:** 完成两个代表应用的广告模式，保护所有已验收透明模式和未验收聊天界面。

**Architecture:** 广告窗口使用独立 `ad-window-controls.mjs`，不注册到现有透明窗口控制器；老板键保留旧控制器调用，再通知广告遮挡策略。独立广告页面控制器负责生命周期、设置、阅读滚动与视频适配。正式聊天文件不修改。

**Tech Stack:** Electron、Vue 3、Node test runner、离线 Electron 烟测。

## 任务与验证

- [ ] 1. 备份 src/tests/scripts/docs/package；记录所有透明视图/features、窗口控制器/定义/guest guard、两个聊天视图 SHA256；执行 `npm test` 获取基线。
- [ ] 2. 新增 `tests/ad-modes.test.mjs`：验证广告默认设置/范围限制/链接校验/隔离命名空间、页面导航失效、滚动遮挡恢复、广告老板键只发遮挡不隐藏。新增静态集成约束测试并运行看到失败。
- [ ] 3. 新增 `src/shared/ad-modes.mjs`：`AD_MODES` 映射 douyin/weReadAd；`normalizeAdSettings(kind, value)` 返回隔离广告设置；`validateAdUrl(kind, url)` 拒绝非 HTTP(S) 与错误站点。视频 zoom .2；阅读 zoom .7；speed 3；自动滚动关闭；滚动条隐藏。
- [ ] 4. 新增 `src/main/ad-window-controls.mjs`：注册广告窗口、保存广告窗口位置/尺寸、查询当前遮挡状态、全局遮挡切换、关窗、放大/缩小。所有事件发送前检查窗口/contents 是否销毁，窗口关闭后清理。
- [ ] 5. 新增 `features/ad-modes/controller.mjs` 与 `page-scripts.mjs`：设置只存于 `adModes.<kind>`；串行操作和 generation 检查；视频准备/全屏/前后/喜欢/暂停；阅读自动滚动/滚动条；遮挡暂停阅读而不重建 guest；导航失效/卸载清理。
- [ ] 6. 新增 `VideoAdView.vue`、`ReadingAdView.vue` 和本地遮挡图片。视频有广告头、内容切换、放大、透明切换、关闭；小窗拦截网页点击而放大后解除。阅读有广告头、颜色、关闭、设置、字号、速度、自动滚动、滚动条、广告文字、真实阅读控制栏按钮。遮挡铺满内容但保留头栏。
- [ ] 7. 修改 `main/index.js` 仅增加广告注册/专用 IPC/老板键通知/从广告切回既有透明入口；不改透明视图、旧窗口控制器或窗口定义。修改 preload 新增独立 `adModeControl`。修改两个广告路由，并在首页保留透明按钮，增加两个独立广告入口。不接入尚未批准的聊天 UI。
- [ ] 8. 新增 `scripts/ad-modes-smoke.cjs` 与 runner；离线 URL 夹具，真实 Electron 桥接和 DOM；验证布局无旧控件、设置/滚动、遮挡/恢复、混合透明与广告老板键、关闭、导航、重启恢复。保存两张实际窗口截图供检查。
- [ ] 9. 运行 `npm test`、`npm run build`、新广告烟测和所有现有透明/阅读/窗口烟测；对照 SHA256 确认保护文件无变化；复核原 asar hash。
- [ ] 10. 保存验证记录、启动与验收说明。线上登录/阅读及真实视频适配由实际站点验证补充，不用离线测试冒充线上成功。

## 本批界限

只完成抖音与微信读书广告代表。B站/虎牙/快手/番茄/晋江广告扩展、五模式弹窗、B站/直播控制器、三套聊天网页及正式移植仍按差距清单后续分批完成。

广告皮肤使用本地展示内容，不照搬源软件商业广告外链或遥测。二维码只作本地遮挡图片，不请求第三方二维码服务。透明切换通过显式参数把 URL 交给既有窗口的 guest，不写入或覆盖透明设置。
