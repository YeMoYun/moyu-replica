# 本地阅读模式响应式阅读界面设计

日期：2026-09-24

## 目标

改进“阅读模式 → 本地阅读模式”。保留现有书架和导入流程；用户从书架打开一本书后，阅读界面改为与已验收透明阅读模式相近的紧凑单层工具栏，并支持全书连续纵向滚动、窗口自由缩放和内容自适应。

## 已确认选择

- 采用单层统一工具栏（视觉方案 B）。
- 阅读方式采用全书连续纵向滚动。
- 导入完成后仍停留在书架，由用户点击书籍进入阅读。
- 本地阅读独立实现相同视觉和交互规则，不抽取或修改 `WeReadView.vue`，避免影响任何已验收透明模式。

## 范围

### 包含

- 本地书架打开书籍后的阅读界面。
- TXT、MOBI/AZW/AZW3（当前解析为章节 HTML）和 PDF 查看区域。
- 本地阅读窗口的置顶、鼠标移出隐藏、整体透明度、关闭、隐藏/恢复工具栏和窗口拖动。
- 返回书架、目录、字号减小/增大、上一章/下一章和“更多”。
- 连续滚动进度保存与恢复。
- 窄窗口下的响应式按钮收纳，以及正文尺寸自适应。

### 不包含

- 不修改微信读书、番茄小说、晋江文学城或其他透明模式。
- 不改变书籍文件解析器或增加新格式。当前 `.epub` 虽出现在选择器中，但主进程没有 EPUB 解析实现；本次不把它误报为可用格式，打开时显示明确中文错误。
- 不自动打开刚导入的书籍。
- 不增加云同步、批注、搜索、朗读或分页翻页动画。

## 界面结构

书架保持现状。进入阅读状态后，窗口自上而下分为：

1. 单层紧凑工具栏。
2. 可滚动正文区域。
3. 可选的轻量阅读位置提示。

工具栏沿用透明阅读模式的深色、无边框、紧凑视觉。固定保留隐藏工具栏、关闭和标题；其余空间按宽度展示置顶、自动隐藏、透明度、返回书架、目录、字号、上一章与下一章。宽度不低于 `560px` 时显示全部操作；`360px–559px` 时保留窗口控制、书架和目录，其余进入“更多”；低于 `360px` 时只固定显示隐藏、关闭、书架和“更多”，标题省略。工具栏不产生横向滚动条。隐藏工具栏后保留一个可点击的恢复按钮。

工具栏空白区域使用 `-webkit-app-region: drag`；所有按钮、滑块、菜单和正文使用 `no-drag`，保证无边框窗口可拖动且内容仍可操作。

## 阅读与导航

### TXT 和当前可解析的章节型电子书

- 将所有章节按顺序渲染在同一个纵向滚动容器中。
- 每章具有稳定章节索引和 DOM 锚点。
- 目录选择、上一章和下一章通过锚点滚动定位，不替换整个正文。
- 章节标题和正文宽度随窗口变化；正文不产生横向滚动条。
- HTML 章节内容继续使用当前解析结果，但在本地阅读容器内限制图片、表格和预格式文本的最大宽度，避免撑破窗口。

### PDF

- PDF 继续使用当前内置查看区域并占满工具栏下方剩余空间。
- 外层窗口控件和响应式尺寸与其他格式一致。
- PDF 内部滚动由 Chromium PDF 查看器负责；本次不承诺应用层精确读取或恢复 PDF 内部页码，避免伪造不可观测进度。

## 进度模型与兼容

TXT、MOBI/AZW/AZW3 使用版本化进度对象：

```js
{
  version: 2,
  kind: 'continuous',
  chapterIndex: 3,
  chapterOffset: 0.42
}
```

`chapterOffset` 是当前章节内的归一化纵向位置。恢复时先找到章节锚点，再按该章节当前渲染高度恢复相对位置，因此改变窗口尺寸后仍能接近原阅读位置。

旧版数字进度继续接受：将其解释为旧章节/分页索引，迁移到最接近的章节锚点；下一次保存时写入新版对象。书架历史结构和 IPC 通道名称保持不变。

滚动保存采用节流；离开阅读状态和窗口卸载前再立即保存一次，避免每个滚轮事件都写入存储。

## 窗口行为

- `bookReader` 继续使用当前独立 BrowserWindow，默认尺寸保持 `400 × 300`。
- 窗口允许拖动边缘自由调整大小，最小尺寸为 `320 × 240`。
- 正文容器采用 flex 布局及 `min-height: 0`，始终填满工具栏以下区域。
- 调整窗口尺寸不重建正文、不重置滚动位置、不要求用户手动横向或上下校正布局。
- 置顶、自动隐藏、透明度、关闭和状态通知使用现有受限 `windowControl` 桥，不为本地阅读增加宽泛 IPC 权限。

## 状态与错误处理

- 书籍读取失败时保留书架历史，并在窗口内显示中文错误；用户可返回书架或重试打开。
- 章节为空时显示“未读取到可显示内容”，工具栏和返回书架仍可用。
- 目录为空时目录按钮禁用或显示明确提示。
- 窗口控制调用失败时显示可关闭的中文错误条，不让界面进入错误的选中状态。
- 字号设置限制在安全范围内，并继续通过现有 `bookReader` 设置持久化。

## 代码边界

- `ReaderView.vue`：书架/阅读状态、统一工具栏、响应式布局和连续正文渲染。
- 本地阅读功能模块：章节标准化、进度计算/迁移、滚动定位和节流保存。该逻辑从视图中分离，便于独立测试。
- `window-definitions.mjs`：仅在需要时补充本地阅读窗口最小尺寸或明确可缩放属性；不改变其他窗口定义。
- `preload/index.js`：优先复用现有 `bookReaderAPI` 和 `windowControl`，只暴露阅读所需的最小接口。
- 主进程：保留现有书架历史和保存通道；只做进度对象兼容所需的验证，不增加任意文件访问能力。

## 验收标准

1. 本地书籍导入后仍停留在书架。
2. 点击书籍进入单层透明阅读风格工具栏界面。
3. TXT、MOBI/AZW/AZW3 章节内容可从头到尾连续纵向滚动。
4. 目录、上一章和下一章定位到连续正文中的正确章节。
5. 关闭并重新打开书籍可恢复接近上次的章节内位置；旧数字进度不会导致报错。
6. 窗口可缩放至 `320 × 240`；放大、缩小和改变宽高比后，正文自动重排，图片不溢出，阅读位置不重置。
7. 窄窗口没有水平滚动条，工具栏按钮不重叠，低频按钮进入“更多”。
8. 隐藏/恢复工具栏、关闭、置顶、自动隐藏和整体透明度均可用。
9. PDF 填满剩余空间并随窗口调整，但不把未验证的 PDF 页码恢复标记为完成。
10. `.epub` 不再被当作 TXT 误读；在没有解析器时显示明确中文错误。
11. 微信读书、番茄小说、晋江文学城和其他透明模式的代码与现有行为不变。

## 测试策略

- 单元测试：章节标准化、旧进度迁移、新进度计算、章节锚点定位和边界值。
- 视图结构测试：工具栏动作完整、隐藏恢复入口存在、连续正文容器存在、窄屏折叠规则存在。
- 主进程/预加载测试：现有本地阅读 IPC 权限不扩大，进度对象能够往返。
- 聚焦构建：运行本地阅读相关测试和 Electron 构建。
- 人工验收：使用真实 TXT、章节型电子书和 PDF 调整窗口尺寸，检查滚动、控件、透明度及位置恢复。
