# 虎牙窗口内全屏修复与晋江、番茄阅读控件统一

日期：2026-09-18。状态：用户已确认执行。

## 用户需求和当前证据

1. 虎牙透明化进入直播间后，点击右下角直播间全屏，直播画面应铺满现有小窗口，不应扩大到整个显示器。
2. 晋江文学城和番茄小说以已验收微信读书为标准，完整更换控件，并接入相应阅读功能。

当前 `/fanQue`、`/jinJiang` 仍使用 SiteView，未使用专属阅读工具栏。现有 WeReadView 已有 30px 紧凑工具栏、“控”、“更多”和四类弹窗。虎牙的 prepareVideoPage 只有视口 CSS，toggleVideoFullscreen 只有 click；没有虎牙窗口内播放器布局、还原和退出处理。main/index.js 统一拒绝 session 权限，包括 HTML 全屏请求。这是需要实测追踪的两条路径，不能把源码静态检查等同于真实直播间复现。

原版虎牙透明组件在 renderer.beautified.js 的 19660 附近识别 #player-wrap/#player-ctrl-wrap/#player-gift-wrap，原版晋江、番茄组件保存各自滚动速度、启用状态和阅读地址。参考只读。

基线：2026-09-18 当前 Node 测试 104 项通过。此前全屏 fixture 验证按钮 click，不验证真正铺满窗口，须新增几何验收。

## 方案比较

推荐：给晋江、番茄新增共用 ReadingSiteView 和各站 adapter；保留微信读书现有文件。虎牙使用平台专属窗口内全屏模块，接入现有视频 controller 的生命周期。这样复用已验收外观，但不会让两站覆盖微信读书设置或让虎牙变更影响抖音。

备选一：分别复制两份阅读组件。边界简单，但今后同一控件修复需要维护三份界面。

备选二：在 SiteView 里大量添加分支。少建文件，但阅读状态和通用网页状态耦合，其他网站回归范围扩大。

## A：虎牙修复设计

- 目标是直播播放器铺满 webview 内容区域，保留应用简约工具栏，不是 BrowserWindow/显示器全屏；不改变窗口位置、尺寸、置顶、透明度和用户手动缩放偏好。
- 诊断实际直播间右下角按钮及请求路径，分别确认站点网页全屏与 Fullscreen API。平台专属适配把此按钮和现有网页全屏快捷键接到同一个窗口内铺满/退出逻辑，不能只为快捷键增加一个可用路径。
- 利用真实播放器容器覆盖窗口内视口；保留真实 video、播放状态和站点控件，不替换成复制的视频。布局自适应当前窗口，按视频比例保留必要黑边。
- 再点按钮或 Escape 退出，恢复进入前的 DOM/样式及滚动位置；导航、刷新、关闭清理监听器和注入，无重复订阅。找不到播放器时显示中文失败，不报告假成功。
- 不把默认 session 的所有权限开放；其他站点、摄像头、麦克风及定位权限保持现状。仅修改虎牙必要路径，不借机重构已验收抖音。

## B：晋江与番茄阅读设计

- 仅替换 `/jinJiang`、`/fanQue` 的页面；微信读书及广告模式不动，现有首页入口、站点真实首页和原版窗口初始尺寸保留。
- 完整对照微信读书工具栏：30px 深色栏，依次隐藏、关闭、置顶、移出隐藏、网页透明、水滴窗口透明度、“控”；中间拖动区，右侧更多/收起。隐藏时保留白色眼睛恢复。移除旧地址框、前进后退文字栏、常驻透明度百分比、原生全屏按钮及移出隐藏复选框。
- 更多：返回对应站点首页、帮助、自动滚动设置、滚动条开关、文字/背景颜色和缩放设置、恢复默认样式。弹窗及按钮外观与微信读书一致，快捷键说明读取配置。
- 网页透明和整窗透明分开；整窗透明范围 .1–1、步长 .01，读取发送方原生窗口状态。文字/背景色、缩放 .6–1 步长 .05、滚动速度 1–10、自动滚动和滚动条开关分别保存。
- “控”适配对应网站的真实目录、上下章和阅读设置控件。只浮出真实可操作控件，收起恢复原 DOM/样式；不直接套用微信的 .readerControls。如果页面没有对应控件，显示明确中文提示，不造不可用的按钮，也不绕过登录/VIP/付费章节限制。
- 自动滚动识别各站真实阅读滚动容器，不只对 window.scrollBy 操作；页底停止。老板键/移出隐藏暂停，恢复时仅恢复原先启用的任务。
- 配置分别使用 fanQue/jinJiang 命名空间，兼容原版对应 Zoom/AutoScrollEnabled/ScrollSpeed 和 lastAddress 字段及现有 localStorage 阅读地址；不覆盖微信读书、其他平台或整窗设置。
- 导航、刷新重新应用样式和偏好；串行保存，失败提示、恢复本模块资源；页面卸载清理动画、监听器、浮层和注入。首页或非阅读页不错误显示阅读控件成功状态。
