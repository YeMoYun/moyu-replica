# 飞书预览：用户截图对齐

用户已确认以 2026-09-18 提供的真实飞书截图作为本轮视觉标准。

## 范围

仅修改 `previews/chat-ui` 的飞书演示。微信、钉钉渲染结构及样式不改；正式 `src` 和源软件只读。无需 Git 提交：当前目录不是 Git 仓库。

## 设计

- 三栏结构：176px 文字导航；会话栏占舞台约 29%，最小 280px；剩余空间为聊天区。各栏之间留 6px 间隔。浅蓝灰渐变桌面背景，列表与聊天区是圆角浅白卡片。
- 导航栏：顶部头像和添加按钮，搜索，消息、豆包工作、云文档、推荐、多维表格、视频会议、通讯录、日历、飞行社、权益升级、更多、历史记录、实验室。未实现的业务入口明确提示未接入。
- 会话栏：消息标题、顶部三个快捷会话、圆形头像、外部/机器人标签、时间和灰色摘要、浅蓝选中项。快捷会话真实切换本地会话。
- 聊天区：群头像与成员/机器人数量、外部标签、操作图标，消息/云文档/群公告/文件/每日质检任务/质检问题收集表页签；群公告条支持关闭和重新显示。非消息页签只提示未接入，不能冒充真实业务页面。
- 消息：圆形头像与姓名、灰色圆角气泡，首条本地演示引用和回复标记。群公告、姓名和正文使用合成数据，不复制截图里的真实人员、账号 ID 和工作内容。
- 播放器放在灰色消息卡片中；仍是本地占位，可试用原有设置、插入、遮挡和恢复。
- 输入区：底部 52px 边框圆角单行外观，文本区左侧、格式/表情/@/截图/插入/设置/放大/发送图标在右侧。保留 Enter 发送、Shift+Enter 换行、草稿、配置及缩放等已有交互。
- 窄窗口：850px 以下压缩导航与会话栏；720px 以下折叠会话栏并保留打开会话按钮，无横向溢出。

## 验证

先添加失败的 Electron DOM/布局断言，再实现。新断言覆盖导航宽度、搜索位置、快捷会话、圆形头像、页签、公告关闭恢复、紧凑输入栏、发送图标及自定义名称转义。运行完整 UI 检查和模型测试；比对修改前后正式 src SHA256，视觉检查飞书标准/宽屏截图以及微信/钉钉未变。
