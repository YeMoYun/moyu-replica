# 三套聊天界面独立预览设计

状态：用户已于本任务确认预览范围；本文记录已批准的方案，不代表正式聊天功能已验收。

## 边界

只新增 `previews/chat-ui/` 与本批文档，不修改 `src/`、正式路由、preload、窗口逻辑、透明模式或只读源软件。不连接微信、钉钉、飞书账号。消息、头像、已读标记、播放器、老板键动画均是明确标注的本地演示。

## 三套布局

- 微信：按只读源 CSS 的 60px 深色导航、250px 会话列表、60px 搜索/聊天标题区、灰色消息区、160px 输入区重建。自己消息绿色，其他消息白色，播放器嵌在消息中。
- 钉钉：按只读源 CSS 的 35px 蓝色顶部搜索区、120px 浅色功能栏、250px 白色会话列表、50px 聊天标题区、圆角输入区重建。自己消息浅蓝，展示演示已读状态。
- 飞书：源程序未包含飞书，提供新增的浅色桌面设计：紧凑导航、消息筛选/搜索、会话列表、标题动作、白色消息区和浅蓝消息气泡。不宣称源软件已有或与某个最新版本逐像素一致。

## 可验收的本地交互

平台切换独立保留演示状态；会话搜索/切换；输入发送（Enter 发送，Shift+Enter 换行）；插入演示播放器；设置站点、横竖屏、80–200% 大小、自/对方发送、交互遮罩；遮挡/恢复；阅读播放器采用文本遮挡；设置和联系人/JSON 配置；恢复演示数据；标准、紧凑、宽屏尺寸和窄视口适配。

视频遮挡以标明的动态图占位演示，不冒充源软件 GIF；阅读与视频遮挡分开。缩放不改变网页交互授权。播放器占位不加载真实网页，不将界面交互通过当作真实站点功能通过。

## 实现与验收

原生 HTML/CSS/JS，零新增运行依赖，双击 `index.html` 可打开。演示存储仅用 `moyu-ui-preview-v1:*`；存储不可用时仍可在内存中操作并提示。配置先校验后替换，非法 JSON 不破坏当前状态。纯模型单测先失败后实现；独立 Chromium 烟测检验三套布局、交互、截图和窄视口；正式源文件逐项哈希对比本批开始基线。

用户分别验收三套界面后才进入正式集成。预览验收前不修改 `ChatSkinView.vue` 或 `ChatConfigView.vue`。
