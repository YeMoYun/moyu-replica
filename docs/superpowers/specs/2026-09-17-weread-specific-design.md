# 微信读书专属页面与交互设计

日期：2026-09-17。状态：用户已确认实施，并明确要求去掉普通微信读书窗口里的全部通用控件，只保留录屏中的简约控件；实施中。

## 目标与依据

以用户提供的约 50 秒微信读书演示和只读原版源码为准，在复刻项目中补齐普通微信读书模式。不是重做微信读书网站：网页仍使用真实的 `https://weread.qq.com/`，专用 Vue 页面负责窗口工具栏、样式注入和网站控制栏交互。

参考：`D:\deepseekharness\MoYuMaster\renderer.beautified.js` 的普通微信读书组件（22172 起）、`main.beautified.js` 的 weRead 配置和隐藏事件。原版 `D:\MoYuMaster-1.0.0-win` 和工作区解包参考全部只读。

## 方案与选择

推荐新增 `WeReadView.vue`，只接管现有 `/weRead` 路由，复用第一批已修复的窗口控制桥。将网页脚本/样式管理抽成独立模块，便于验证恢复与重复调用。

备选是在 `SiteView.vue` 中增加大量 weRead 条件分支。文件数少，但会让通用网站和微信读书状态耦合，增加其他入口的回归风险，不选这一方案。

本次不替换 `/weReadAd`、`/weReadAdOld`，不改其他网站页面，不制作静态假书页。微信读书广告模式是独立皮肤和老板键逻辑，另行对照实施。

## 页面和功能

1. 紧凑顶部栏对照原版：30px 高、深色背景；左侧依次为隐藏操作栏、关闭、置顶、移出隐藏、网页透明、窗口透明度和“控”；中部空白可拖动，按钮不可拖动；右侧“更多/收起”。隐藏栏后保留白色眼睛恢复按钮。按钮有对应 title、可访问名称和开启状态。
   普通微信读书窗口不得保留旧 SiteView 的网址输入框、前进/后退/刷新栏、文字置顶/透明度按钮、百分比常驻显示、全屏按钮、移出隐藏复选框和“显示操作栏”文字按钮。其他网站及广告入口不在本次替换范围内。
2. 网页透明与窗口透明分开：网页透明通过 webview 注入 CSS 移除页面背景，不将文字一并调淡；整窗透明调用发送方定位的窗口控制桥。关闭网页透明时只移除本模块的注入，不误删其他样式。
3. 窗口透明度弹窗对照原版深色样式，滑块范围 0.1–1、步长 0.01，显示数值。快捷键说明读取当前配置，不写死用户已修改的 Ctrl+P/Ctrl+O。弹窗、文字和网页均受整窗透明度影响。
4. 置顶、移出隐藏和关闭复用已有真实主进程行为。以保存透明度恢复窗口。主进程状态同步到按钮；自动滚动在移出或老板键隐藏期间临时暂停，恢复时只恢复此前正在滚动的任务，不擅自开启用户关闭的功能。
5. “控”仅在 `/web/reader/` 阅读地址工作：查找网页真实 `.readerControls`，将其移动到横向浮层，显示真实子按钮，调整提示方向；再次点击恢复 DOM 位置、元素及子元素原有样式、提示方向并移除本模块注入。调出时临时撤销网页透明，收起后恢复之前设置，不将临时撤销写成用户偏好。非阅读页显示可关闭的提示；找不到控件必须报告失败，不能点亮成功状态。
6. “更多”按普通模式源码接入返回微信读书首页、帮助、自动滚动设置、显示/隐藏滚动条、样式设置、恢复默认样式。自动滚动速度 1–10，使用累计像素的平滑滚动并在页底停止；Ctrl+E 对应既有停止/继续动作。样式包含背景/文字颜色与网页缩放（0.6–1、步长 0.05）。恢复默认清除本模块样式/偏好并重载页面，不清空其他应用配置。
7. 读取并兼容原版的 `weRead.transparent`、`weRead.backgroundColor`、`weRead.fontColor`、`weRead.lastAddress`、`weReadZoom`、`weReadAutoScrollEnabled`、`weReadScrollSpeed`。窗口透明度和置顶等以现有 `windowState.weRead` 为权威，继续兼容第一批支持的旧字段。不清空用户数据。初次网页地址兼容现有 localStorage 地址，之后由持久配置和真实导航更新。
8. dom-ready/页面导航后重新应用用户样式、缩放和滚动条设置；清理失效的控制浮层状态。订阅、计时器和注入脚本在页面卸载/窗口关闭时清理，异步失败显示在专属界面，不吞掉异常或报告假成功。

## 验证与边界

采用测试驱动开发，先观察失败再实现。回归覆盖透明切换/刷新重注入、临时透明恢复、控件缺失/非阅读页提示、真实 DOM 恢复、重复调用不累积、透明度与置顶互不影响、配置保存重启、隐藏/老板键与滚动暂停恢复、卸载清理和错误显示。

真实 Electron 检查使用独立临时 userData，阻止远程 HTTP(S)，加载本地阅读模拟页面（包含真实选择器及可滚动内容），验证实际 webview 脚本和页面按钮；不能以本地模拟宣称线上站点验收通过。运行完整 Node 回归、production build、第一批冒烟和专属冒烟。

微信读书的登录、账户、书库、会员权限由真实网站提供，不复制/绕过网站权限，不连接原版授权服务器。线上 DOM 可能变化；实网人工阅读、实体全局快捷键和录屏视觉一致性作为单独验收项保留。自动化检查不等同于这些人工体验完成。

## 方案自检

普通模式与广告模式边界明确；网页透明与窗口透明分别定义；“控”使用真实 DOM 且有完整恢复；临时暂停/透明变化不改用户偏好；其他页面继续使用原组件；没有要求修改只读原版、删除用户数据或伪造外部权限。
