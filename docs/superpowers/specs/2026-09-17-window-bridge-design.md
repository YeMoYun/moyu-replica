# 第一批：窗口通信、快捷键与状态保存

## 目标与边界

按照用户确认的顺序，先修复现有控件和底层行为的断链，再完善专属功能，最后对齐视觉细节。

- 原版 `D:\MoYuMaster-1.0.0-win` 严格只读；工作区参考文件也不修改。
- 仅修改 `D:\deepseekharness\moyu-replica`。
- 本批不重做页面外观，不实现支付、不连接原版授权服务器、不操作系统任务栏或外部应用。
- 本批交付不等于 44 个页面全部与原版一致；阅读解析、聊天配置、推荐列表和直播联动分批实施。

## 已核实的基础

原版与工作区副本的 app.asar 哈希一致。关键解包文件与归档内字节一致。复刻项目覆盖 44 条路由，16 个 Vue 页面组件静态编译无错误。项目未配置自动测试命令，当前目录不是 Git 仓库，不能进行 Git 提交；不擅自初始化仓库。

现有问题包括：默认快捷键字段与注册动作字段不同；网页全屏按钮执行置顶；透明度按钮发送无人处理的事件；自动隐藏设置错误地改变任务栏显示；窗口工厂没有恢复保存的状态；preload 事件订阅缺少可靠的解绑机制。

## 方案比较

1. 推荐：保留 Vue 页面和原有接口名称，按调用链修复，提取小型窗口控制与快捷键模块，添加隔离测试。改动可控，也便于逐项与原版核对。
2. 逐页打补丁：初期改动较少，但相同错误容易在各页面重复，窗口状态难以保持一致。
3. 全面重写：可以重新划分结构，但扩大回归风险，延后已有功能恢复，不作为当前方案。

## 架构与数据流

渲染层控件或全局快捷键 → 统一动作 → preload/IPC → 目标窗口行为 → 保存设置 → 界面状态同步。

- 窗口工厂：负责创建、复用、关闭和恢复窗口设置；对照原版实际入口设置尺寸、边框和透明模式，不直接套用所有窗口同一套选项。
- 窗口控制：负责窗口透明度、置顶、窗口全屏和鼠标移出隐藏。网页播放器全屏与窗口全屏必须区分；网页播放器专属全屏留给对应平台功能批次，不能用置顶冒充。
- 快捷键：默认字段与设置页一致，兼容已有旧字段；注册失败和冲突必须返回可见错误，不能吞掉异常。需要平台网页脚本支持的点赞、上一项、下一项不得宣称已恢复，仅先保证动作正确分发。
- 订阅：preload 返回解除订阅的方法，页面卸载时释放监听，避免重复执行。
- 存储：保留用户已有配置，兼容旧键，保存每个窗口的透明度、置顶、自动隐藏和位置尺寸；磁盘写入失败必须上报，不展示假成功。

## 本批行为要求

1. 透明度控件作用于所属窗口，数值限制在有效范围，不改变主窗口或其他窗口。
2. 置顶和窗口全屏是独立操作；关闭透明模式窗口使用正确窗口标识。
3. 自动隐藏与跳过任务栏独立。对照原版的鼠标位置检测、透明度恢复和输入穿透策略实现，提供退出隐藏状态的途径；隐藏不是关闭窗口。
4. 老板键遵循原版行为并对照验证；恢复时不能擅自展示此前由用户单独隐藏的窗口。
5. 快捷键保存后立即生效，重启后保留。旧字段迁移不得丢失用户自定义键位；没有原生绑定模块时，“绑定软件”明确提示不可用，不能返回成功或改为操作自身窗口。
6. 关闭与重开窗口恢复有效设置；屏幕变化后校正完全超出工作区的位置，保持窗口可找回。
7. 不通过清空用户配置获得测试通过；不执行现有会清空配置的 full-sweep 脚本。

## 验证与验收

- 使用 Node 内置测试框架，先写失败用例，再修复生产代码；尽量测试真实逻辑，只在 Electron/屏幕/时钟边界使用必要替身。
- 覆盖旧快捷键迁移、动作分发、注册失败、透明度范围、窗口标识、自动隐藏恢复、老板键状态、窗口设置往返和监听解绑。
- 真实 Electron 冒烟运行使用独立临时 userData 和本地测试内容，避免原版与用户配置、登录请求和线上网站的不稳定因素。
- 验证窗口透明度、置顶、窗口全屏、关闭重开、状态恢复和监听不重复。全局快捷键是否触发需实际运行验证，不能以事件分发单测替代。
- 最后运行完整回归测试和 electron-vite build，记录通过、失败及未验证项。测试环境清理只针对本次明确创建的临时目录。
