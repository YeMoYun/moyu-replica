# 微信截图版独立预览验证

日期：2026-09-18。范围：`previews/chat-ui`，不接入正式应用。

## 实现与参考

按用户微信截图调整深色导航、照片头像、灰色会话列表、项目小组标题、三条默认消息、简约工具栏与输入区。默认群聊不插入播放器，保留大面积留白。播放器设置、聊天配置移到标题右上「更多」；文件夹按钮仍可插入本地演示播放器。

8 张头像是只读源项目自带演示素材的副本，源文件未编辑。非真实账号，播放器仍是本地演示，不代表线上视频已接入。

## 测试证据

- 新增模型/UI 断言在实现前捕捉到旧版默认群聊和底部设备入口不符合参考。列表排序改变后，旧测试“数组第一个就是当前会话”的假设调整为 `M.current(s)`。
- `node --test previews/chat-ui/model.test.mjs`：11 通过，0 失败。
- `node previews/chat-ui/run-verify.mjs`：38 通过，0 失败；覆盖菜单开关、外部点击/Escape、Ctrl+Enter 换行、Enter 发送、头像解码、配置安全、遮挡和播放器演示、平台数据隔离、320/375/414/768px 无横向溢出。
- 验证器无外部资源或真实账号访问，无 renderer 错误。Windows Chromium 的网络探测输出一次 WSALookupServiceBegin 10108 环境警告，不影响检查结果。
- 独立 Chrome 实际点击「更多」及播放器设置，关闭后输入并按 Enter 发送；快照包含发送文本，浏览器 console 0 错误、0 警告。测试浏览器会话已关闭。
- 本机 `127.0.0.1:4186` 页面及 8 张新增头像均返回 200，图片 MIME 为 image/jpeg。
- 正式 `npm test`：127 通过，0 失败。
- 正式 `src/` 62 个文件的路径和 SHA256 与修改前记录完全一致；所有透明模式保持不动。

## 外观与隔离

已查看微信标准、宽屏与窄屏截图；初始参考场景保存在 `previews/chat-ui/output/wechat-reference.png`。飞书、钉钉渲染与默认模型分支不修改。

全页 PNG 哈希不能单独证明隔离：钉钉与先前基线不同，未将其记录为完全相同；飞书一次重跑与基线相同。新增验证临时移除所有微信专属 CSS 后，逐节点比较飞书、钉钉的 DOM 文本、class、几何及计算外观数值，均完全一致。测试结束恢复样式。

## 验收入口

访问 http://127.0.0.1:4186 并选择微信。保留旧演示数据时，从「更多 → 聊天配置 → 恢复本套演示数据」重置当前微信预览。仅预览更改，等待用户验收后再讨论正式集成。
