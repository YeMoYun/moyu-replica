# 飞书模式（抖音气泡）启动与验收

1. 在 PowerShell 中运行：

   ```powershell
   cd D:\deepseekharness\moyu-replica
   npm run dev
   ```

2. 首页点击“飞书模式”，确认左侧 176px 文字导航、10 个会话、快捷会话、7 个页签、群公告和 52px 输入栏。
3. 确认首次打开只有本地灰色视频卡片，没有抖音网页、WebView 或登录请求。
4. 输入消息，检查 Enter 发送、Shift+Enter 换行、切换会话后草稿保留，以及搜索过滤。
5. 关闭群公告，再从“群公告”页签恢复；其他业务页签应提示“功能未接入，仅保留飞书外观”。
6. 点击输入栏“＋”，确认真实抖音气泡在当前小窗口内加载，可直接点击、滚轮和登录，不需要放大原生窗口。
7. 打开播放器设置，调整地址、方向、大小、发送方和交互遮罩，确认已有网页气泡不会被重建。
8. 同时打开微信、钉钉、飞书，确认消息、配置、窗口位置和登录状态互不共享。
9. 使用老板键，确认三个聊天窗口保持可见，只遮挡播放器；再次按下恢复同一个网页气泡。
10. 关闭重开并重启程序，确认消息、草稿、公告状态、配置与播放器地址恢复。

自动化只使用本地离线网页夹具，不访问真实账号；真实抖音登录、推荐流和在线播放需要在本机人工验收。
